## Overview
This project was developed during my Data Science internship at Cognifyz Technologies. The goal was to build a predictive machine learning model to estimate restaurant ratings based on multiple features such as location, cuisines, pricing, and user feedback.


## Problem Statement
Restaurant rating systems are influenced by several variables including menu pricing, food quality, ambiance, and customer experience. The objective was to:
- Predict restaurant ratings using regression techniques
- Evaluate multiple ML models to choose the best performing one
- Deploy the model and make it user-friendly for real-time use


## Tech Stack & Tools
- Language: Python  
- Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Joblib  
- Deployment: Streamlit


## Features
- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Feature Engineering  
- Regression Models:
  - Linear Regression
  - Decision Tree Regressor
  - Random Forest Regressor
  - Gradient Boosting Regressor  
- Hyperparameter Tuning using GridSearchCV  
- Model Serialization using `joblib`  
- Streamlit Web App for predictions
